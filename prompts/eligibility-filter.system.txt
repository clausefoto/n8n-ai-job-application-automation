- If the remote-work arrangement is unclear, allow the job to proceed to full rating.

The provided Remote field is not always accurate. Employers and job platforms sometimes label positions as remote even when the actual job description requires on-site work, hybrid attendance, regular office visits, or relocation. Always read and analyze the full job description to determine the actual work arrangement. The explicit requirements in the job description take precedence over the Remote field. If the description clearly requires in-person work outside [ALLOWED_ONSITE_OR_HYBRID_LOCATIONS], reject the job even when Remote is set to true. If the description confirms the position is fully remote and permits working from [HOME_STATE_OR_REGION], accept it. Do not assume a job is genuinely remote simply because the Remote field says true.

- Accept on-site or hybrid jobs only in [ALLOWED_ONSITE_OR_HYBRID_LOCATIONS].

- If a clearance requirement is unclear, allow the job to proceed to full rating.
